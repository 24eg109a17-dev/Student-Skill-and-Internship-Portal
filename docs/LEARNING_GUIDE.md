# Learning Guide

| Concept | What it is | Why used | Where |
|---|---|---|---|
| Java | JVM language | Backend implementation | Entities/services |
| Spring Boot | Java app framework | Fast REST application setup | Backend |
| Spring MVC | HTTP web framework | Controllers/endpoints | Controllers |
| REST | Resource-oriented HTTP API | Frontend/backend communication | `/api/**` |
| Dependency Injection | Framework supplies dependencies | Loose coupling | Constructors |
| IoC | Framework controls object lifecycle | Consistent configuration | Spring beans |
| JPA | Persistence abstraction | Map Java objects to tables | Entities/repositories |
| Hibernate | JPA implementation | SQL generation/object mapping | Runtime |
| Repository | Persistence interface | CRUD/query operations | `repository/` |
| Service | Business layer | Keep rules out of controllers | `service/` |
| DTO | Data transfer object | Control API payloads | `dto/` |
| JWT | Signed bearer token | Stateless API authentication | `security/` |
| CORS | Browser origin policy | Allow React origin | `SecurityConfig` |
| MySQL | Relational DB | Durable normalized data | `database/` |
| React | UI library | Component-based frontend | `frontend/src` |
| Props | Component inputs | Reusable components | React |
| State | Component data | Interactive UI | React hooks |
| useState | State hook | Form/search state | Pages |
| useEffect | Effect hook | API loading | Pages |
| React Router | Client routing | Multiple views | `App.jsx` |
| Axios | HTTP client | REST requests | `api.js` |
| JSON | Data format | API payloads | REST |
| HTTP methods | GET/POST/PUT/DELETE | CRUD semantics | APIs |
| Status codes | HTTP result classes | Clear client behavior | REST |
| BCrypt | Password hashing | Never store plaintext | Auth |
| Protected route | UI access guard | Hide role pages | React |
