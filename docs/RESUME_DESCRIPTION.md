# Resume and GitHub

## Title
Student Skill and Internship Portal — Java Full Stack

## Two-line description
Built a full-stack internship portal where students manage profiles and skills, discover internships, apply and track application status. Implemented role-based admin management with React, Spring Boot, Spring Security/JWT, JPA/Hibernate and MySQL.

## Resume bullets
- Developed REST APIs for student profiles, skills, internships and internship applications using Spring Boot and Spring Data JPA.
- Implemented BCrypt/JWT authentication, role-based authorization, validation, global exception handling and application business rules.
- Built a responsive React interface with Axios, React Router, backend-powered internship search and admin application-status management.

## Stack
Java 21, Spring Boot, Spring Security, JWT, JPA/Hibernate, MySQL, React, JavaScript, Axios, Maven.
