# GitHub Guide

Recommended repository name: `student-skill-internship-portal-java-full-stack`

```bash
git init
git add .
git commit -m "Initial full-stack portal"
git branch -M main
git remote add origin <YOUR_REPOSITORY_URL>
git push -u origin main
```

Before pushing:
- Never commit `.env`.
- Review `git status`.
- Use `.env.example`.
- Do not put production credentials in SQL or README.
- Use meaningful commits and feature branches for future work.
